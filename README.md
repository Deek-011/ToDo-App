# MERN To-Do App

A simple full-stack To-Do application built using the **MERN stack** (MongoDB, Express.js, React, Node.js).

---

##  Features

- Add and delete tasks
- Data persistence with MongoDB
- Clean and minimal UI with React

---

##  Technologies Used

- MongoDB
- Express.js
- React
- Node.js
- Axios
- Mongoose
- CORS
- Body-Parser

---
